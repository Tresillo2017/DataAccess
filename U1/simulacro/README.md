# Simulacro examen JDBC (jueguicos)

Lo que daría el profesor:
- `ENUNCIADO.md` – enunciado
- `jueguicos.sql` – base de datos
- `src/util/ConexionBBDD.java` – clase de conexión (ya hecha)
- `lib/mysql-connector-java-5.1.47.jar` – driver JDBC

Tú creas: `src/modelo/Usuario.java`, `src/dao/UsuarioDAO.java`, `src/app/Main.java`.

Arrancar la BBDD: `DB_PASSWORD=mysql ./db.sh start` (desde la raíz del repo).
