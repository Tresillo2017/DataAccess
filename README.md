# DataAccess

Coursework for the **Acceso a Datos** (Data Access) subject — 2nd year DAM, UCAM.

## Structure

- `U1/acceso` — IntelliJ IDEA project for Unit 1 exercises (database connection basics).

## Requirements

- JDK 17+
- IntelliJ IDEA
- MySQL (see `mysql-connector-java-5.1.47.jar` for the JDBC driver used in examples)
